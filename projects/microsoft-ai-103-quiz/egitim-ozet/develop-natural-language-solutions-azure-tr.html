Modül 01 / 07

Analyze text with Azure Language in Foundry ToolsMetinden dil, varlık (entity) ve kişisel bilgi (PII) çıkarma — bu kursun "metin" hattının ilk adımı.

Bu modül aslında ne anlatıyor?

Azure Language, Foundry Tools şemsiyesi altındaki hazır bir NLP servisidir (önceki kurslardaki "Foundry Tools" kavramını hatırla). Bir generative AI modeline "bu metindeki kişi/yer isimlerini bul" demek yerine, bunun için özel olarak eğitilmiş, deterministik ve hızlı bir servis kullanırsın.

3 temel yetenek

Detect languageMetnin hangi dilde yazıldığını algılar
Extract entitiesMetindeki kişi, yer, tarih, organizasyon gibi adlandırılmış varlıkları (named entities) bulur
Extract PIIKişisel bilgileri (isim, telefon, TC no vb.) bulur ve isteğe bağlı olarak redakte eder (üstünü çizer)
Quiz'de sorulan iki senaryo — doğru aracı seçme

"Haber makalelerini analiz edip indeksleme için kişi, yer, tarih çıkaran bir uygulama nasıl yaparsın?" → Generative AI modeline regex tool eklemek değil, PII değil — named entity extraction kullanırsın (Azure Language).

"Müşteri yorumlarını web sitesinde yayınlamadan önce kişisel bilgileri temizlemen gerekiyor" → Dili algılayıp sadece İngilizce olanları yayınlamak değil, yapay yorumlar üretmek hiç değil — PII entity'lerini bulup redakte etmek.

💻 Çalışır kod: Üç yeteneği de tek script'te dene

metin_analizi.py
import os
from dotenv import load_dotenv
from azure.core.credentials import AzureKeyCredential
from azure.ai.textanalytics import TextAnalyticsClient

load_dotenv()
client = TextAnalyticsClient(
    endpoint=os.environ["AZURE_LANGUAGE_ENDPOINT"],
    credential=AzureKeyCredential(os.environ["AZURE_LANGUAGE_KEY"]),
)

metin = "Ahmet Yilmaz, 15 Mart 2024'te Istanbul'dan Ankara'ya seyahat etti. Telefonu 0532-555-1234."

# --- 1) Dil algılama ---
dil_sonucu = client.detect_language(documents=[metin])[0]
print(f"Algılanan dil: {dil_sonucu.primary_language.name} (güven: {dil_sonucu.primary_language.confidence_score:.2f})")

# --- 2) Named entity extraction ---
entity_sonucu = client.recognize_entities(documents=[metin])[0]
print("\nBulunan varlıklar (entities):")
for entity in entity_sonucu.entities:
    print(f" - {entity.text} ({entity.category}, güven: {entity.confidence_score:.2f})")

# --- 3) PII tespiti ve redaksiyon ---
pii_sonucu = client.recognize_pii_entities(documents=[metin])[0]
print("\nBulunan kişisel bilgiler (PII):")
for entity in pii_sonucu.entities:
    print(f" - {entity.text} ({entity.category})")
print(f"\nRedakte edilmiş metin: {pii_sonucu.redacted_text}")

Çalıştırmak için: python metin_analizi.py

Neden generative AI değil de bu servis?

GPT tabanlı bir modele "bu metindeki kişileri bul" desen de çalışabilir, ama Azure Language deterministiktir (aynı girdi her zaman aynı çıktıyı verir), çok daha ucuzdur ve token limiti gibi kısıtları yoktur. Bu yüzden production'da toplu metin işleme için genelde önce bu servisler tercih edilir; generative AI, daha "yaratıcı" görevler için saklanır.

Sık karıştırılan noktalar (quiz odaklı)

Haber makalelerinden indeksleme için kişi/yer/tarih çıkaran bir uygulamayı nasıl kurarsın?
Azure Language ile named entity extraction kullanırsın. Regex tabanlı bir generative AI tool'u ya da PII extraction (bu, gizlemek için kullanılır, indekslemek için değil) doğru yaklaşım değildir.
Müşteri testimonial'larını yayınlamadan önce kişisel detayları kaldırman gerekiyor, ne yaparsın?
Azure Language ile PII entity'lerini bulup redakte edersin. Sadece İngilizce olanları yayınlamak (dil filtreleme, konuyla ilgisiz) ya da yapay yorumlar üretmek (orijinal içeriği değiştirir, amaç bu değil) yanlış yaklaşımlardır.

Modül 02 / 07

Develop a text analysis agent with the Azure Language MCP serverModül 1'deki yetenekleri, kod yazmadan bir agent'ın "araç kataloğuna" ekleme.

Bu modül aslında ne anlatıyor?

Modül 1'de TextAnalyticsClient ile doğrudan SDK çağrısı yaptın. Bu modülde aynı yetenekleri (dil algılama, entity, PII) bir MCP server aracılığıyla bir Foundry agent'ına sunuyorsun — agent, kullanıcının doğal dil isteğine göre hangi aracı çağıracağına kendisi karar veriyor (2. kursun Modül 3'ünü hatırla: MCP server barındırır, client keşfeder).

Azure Language MCP server'ın rolü

Birincil rolü: Azure Language'ın metin analizi yeteneklerini, agent'ların kullanabileceği MCP araçları olarak sunmak. Özel dil modelleri eğitmek ya da Azure aboneliğinde büyük dil modelleri deploy/yönetmek değildir — sadece var olan Language yeteneklerini MCP protokolüyle "paketler".

Agent hangi aracı çağıracağına nasıl karar verir?

Agent, MCP server'dan aldığı araç açıklamalarını (tool descriptions) kullanıcının prompt'uyla eşleştirir. Geliştirici her prompt için özel yönlendirme mantığı yazmaz, MCP server da prompt'u analiz edip otomatik yönlendirme yapmaz — karar mekanizması modelin kendisindedir (2. kursun "function calling" mantığını hatırla: model, açıklamaları okuyup karar verir).

Kimlik doğrulama

Azure Language MCP server'ı bir Foundry agent'ına bağlarken kullanılan yöntem: anahtar tabanlı kimlik doğrulama, Ocp-Apim-Subscription-Key credential'ı ile. OAuth 2.0 + istemci sertifikası değil, anonim erişim de değil.

💻 Çalışır kod: Language MCP server'ı Foundry agent'ına bağlama

Bağlantı, Foundry portalında (Agent tanımına "Connect a tool → MCP" ile) veya SDK'da bir mcp tool tanımıyla yapılır. Anahtar, MCP sunucusuna giden isteklerde bir header olarak eklenir:

language_mcp_agent.py
import os
from dotenv import load_dotenv
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import PromptAgentDefinition

load_dotenv()
project = AIProjectClient(
    endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
    credential=DefaultAzureCredential(),
)

# Azure Language MCP server'ını agent'a bir araç olarak tanıt.
# headers içindeki Ocp-Apim-Subscription-Key, MCP server'ın kendisini
# doğrulamak için kullandığı anahtar tabanlı kimlik doğrulamadır.
agent = project.agents.create_version(
    agent_name="MetinAnaliziAgent",
    definition=PromptAgentDefinition(
        model=os.environ["AZURE_AI_MODEL_DEPLOYMENT_NAME"],
        instructions=(
            "Sen metin analizi yapan bir asistansın. Kullanıcının metinlerinde "
            "dil algılama, varlık çıkarma veya kişisel bilgi tespiti gerektiğinde "
            "Azure Language araçlarını kullan."
        ),
        tools=[
            {
                "type": "mcp",
                "server_label": "azure-language",
                "server_url": "https://<bolgen>.api.cognitive.microsoft.com/language/mcp",
                "headers": {"Ocp-Apim-Subscription-Key": os.environ["AZURE_LANGUAGE_KEY"]},
            }
        ],
    ),
)
print(f"Agent oluşturuldu: {agent.name}")

Agent'ı OpenAI Responses API ile çağırma

Python istemci uygulamasında, önceki kurstan (2. kurs, Modül 1) hatırlayacağın gibi bir Foundry agent'ını Responses API ile çağırırken agent'ı extra_body içindeki agent_reference alanında adıyla belirtirsin — API key'i header olarak geçmek ya da endpoint URL'sini model parametresi olarak vermek değil:

agent_cagir.py
from azure.ai.projects import AIProjectClient
from azure.identity import DefaultAzureCredential
import os
from dotenv import load_dotenv

load_dotenv()
project = AIProjectClient(
    endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
    credential=DefaultAzureCredential(),
)
openai_client = project.get_openai_client()

response = openai_client.responses.create(
    input="Şu metindeki kişi ve yer isimlerini bul: 'Ayşe, geçen hafta İzmir'e gitti.'",
    extra_body={
        "agent_reference": {"name": "MetinAnaliziAgent", "type": "agent_reference"}
    },
)
print(response.output_text)

Çalıştırmak için: az login sonra python agent_cagir.py (önce language_mcp_agent.py'yi çalıştırıp agent'ı oluşturmuş olmalısın)

Modül 03 / 07

Develop a speech-capable generative AI application"Ses" hattının ilk adımı — GPT-4o ailesinin ses modelleriyle en basit yol.

Bu modül aslında ne anlatıyor?

Klasik Azure Speech SDK'sına geçmeden önce (Modül 4), bu modül daha yeni ve daha basit bir yolu gösteriyor: Azure OpenAI'ın GPT-4o tabanlı ses modelleri, önceki kurslarda öğrendiğin openai Python paketiyle, neredeyse metin modelleriyle aynı kolaylıkta çağrılabilir.

İki model, iki yön

gpt-4o-mini-transcribeSesten metin üretir (speech-to-text) — audio.transcriptions endpoint'i
gpt-4o-mini-ttsMetinden doğal sesli ses üretir (text-to-speech) — audio.speech endpoint'i, ton talimatı verilebilir
Quiz'de doğrudan sorulan model eşleştirmesi

"Sesten metin üretmek için hangi model?" → gpt-4o-mini-transcribe (gpt-4o-mini veya gpt-4o-mini-tts değil).
"Metinden ses sentezlemek için hangi model?" → gpt-4o-mini-tts (transcribe değil — isimlerdeki "transcribe" ve "tts" son ekleri yönü gösterir).

Ortak kod deseni ("The Code Pattern")

Modülün kendi anlatımına göre, TTS ile STT aynı 4 adımlı akışı takip eder, sadece yön tersine döner:

1) İstemciyi oluştur → AzureOpenAI(endpoint, key, api_version) 2) API'yi çağır → client.audio.speech.with_streaming_response.create(...) (STT için: client.audio.transcriptions.create(...)) 3) Yapılandır → model adı, ses (voice), metin, opsiyonel ton talimatı 4) Dosyaya akıt (stream)→ Cevap doğrudan bir ses dosyasına yazılır

💻 Çalışır kod: Metinden sese (TTS)

metin_den_ses.py
import os
from pathlib import Path
from dotenv import load_dotenv
from openai import AzureOpenAI

load_dotenv()
client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    api_version="2025-03-01-preview",
)

speech_file_path = Path(__file__).parent / "cikti.mp3"

with client.audio.speech.with_streaming_response.create(
    model="gpt-4o-mini-tts",       # text-to-speech modeli
    voice="coral",
    input="Bugün harika bir gün, hadi bir şeyler inşa edelim!",
    instructions="Neşeli ve pozitif bir tonda konuş.",   # sadece gpt-4o-mini-tts'de var
) as response:
    response.stream_to_file(speech_file_path)

print(f"Ses dosyası oluşturuldu: {speech_file_path}")

💻 Çalışır kod: Sesten metne (STT)

ses_den_metin.py
import os
from dotenv import load_dotenv
from openai import AzureOpenAI

load_dotenv()
client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    api_version="2025-03-01-preview",
)

with open("cikti.mp3", "rb") as audio_file:
    transkript = client.audio.transcriptions.create(
        model="gpt-4o-mini-transcribe",   # speech-to-text modeli
        file=audio_file,
    )

print("Transkript:", transkript.text)

Çalıştırmak için: önce python metin_den_ses.py (bir mp3 üretir), sonra python ses_den_metin.py (aynı mp3'ü metne çevirir) — böylece döngüyü uçtan uca görürsün.

Modül 4 ile farkı ne olacak?

Bu modüldeki yaklaşım generative AI ekosisteminin (OpenAI API ailesi) bir parçasıdır — hızlı, basit, "instructions" ile ton kontrolü sağlar. Bir sonraki modülde göreceğin klasik Azure Speech SDK ise daha "geleneksel" bir speech servisidir: SSML ile milimetrik kontrol, gerçek zamanlı mikrofon akışı, 400'den fazla nöral ses ve dil desteği sunar. İkisi de geçerli yollar — seçim, ihtiyacın olan kontrol seviyesine göre değişir.

💻 Çalışır kod: Dosyadan konuşma tanıma (Speech-to-Text)

konusma_tanima.py
import os
from dotenv import load_dotenv
import azure.cognitiveservices.speech as speechsdk

load_dotenv()
speech_config = speechsdk.SpeechConfig(
    subscription=os.environ["SPEECH_KEY"],
    region=os.environ["SPEECH_REGION"],
)

# AudioConfig: girdinin bir ses DOSYASI olduğunu belirtir (mikrofon değil)
audio_config = speechsdk.audio.AudioConfig(filename="ornek_ses.wav")

speech_recognizer = speechsdk.SpeechRecognizer(
    speech_config=speech_config,
    audio_config=audio_config,
)

result = speech_recognizer.recognize_once()

# Kritik alan: result.reason
if result.reason == speechsdk.ResultReason.RecognizedSpeech:
    print(f"Tanınan metin: {result.text}")
elif result.reason == speechsdk.ResultReason.NoMatch:
    print("Konuşma tanınamadı.")
elif result.reason == speechsdk.ResultReason.Canceled:
    detay = result.cancellation_details
    print(f"İptal edildi: {detay.reason} — {detay.error_details}")

SSML ile ince ayar

SSML (Speech Synthesis Markup Language), sesin nasıl konuşacağını XML benzeri etiketlerle kontrol eder — ses seçimi, konuşma tarzı (cheerful, empathetic...), perde/hız, telaffuz, duraklamalar ve gömülü ses klipleri dahil:

ssml_ornek.py
import os
from dotenv import load_dotenv
import azure.cognitiveservices.speech as speechsdk

load_dotenv()
speech_config = speechsdk.SpeechConfig(
    subscription=os.environ["SPEECH_KEY"],
    region=os.environ["SPEECH_REGION"],
)
audio_config = speechsdk.audio.AudioOutputConfig(filename="ssml_cikti.wav")
synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config, audio_config=audio_config)

ssml = """<speak xmlns="http://www.w3.org/2001/10/synthesis"
       xmlns:mstts="http://www.w3.org/2001/mstts"
       version="1.0" xml:lang="tr-TR">
  <voice name="tr-TR-EmelNeural">
    <mstts:express-as style="cheerful">
      <prosody rate="+5%" pitch="+2%">
        Tebrikler! Bu modülü başarıyla tamamladın.
      </prosody>
    </mstts:express-as>
  </voice>
</speak>"""

# SSML kullanırken speak_ssml_async çağrılır (speak_text_async değil)
result = synthesizer.speak_ssml_async(ssml).get()
print("Tamamlandı" if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted else "Hata")

agent = project.agents.create_version(
    agent_name="SesliAsistan",
    definition=PromptAgentDefinition(
        model=os.environ["AZURE_AI_MODEL_DEPLOYMENT_NAME"],
        instructions=(
            "Sen sesli içerik üreten bir asistansın. Kullanıcı bir metni seslendirmeni "
            "istediğinde text-to-speech aracını, bir ses dosyasını yazıya dökmeni "
            "istediğinde speech-to-text aracını kullan. Kullanıcı belirli bir ses istemezse "
            "varsayılan olarak doğal, net bir ses seç."
        ),
        tools=[
            {
                "type": "mcp",
                "server_label": "azure-speech",
                "server_url": "https://<bolgen>.api.cognitive.microsoft.com/speech/mcp",
                "headers": {
                    "Ocp-Apim-Subscription-Key": os.environ["SPEECH_KEY"],

voice_live_agent.py
import asyncio, os
from dotenv import load_dotenv
from azure.core.credentials import AzureKeyCredential
from azure.ai.voicelive.aio import connect
from azure.ai.voicelive.models import (
    RequestSession, Modality, InputAudioFormat, OutputAudioFormat,
    ServerVad, ServerEventType, AzureStandardVoice,
)

load_dotenv()

async def main():
    async with connect(
        endpoint=os.environ["AZURE_VOICELIVE_ENDPOINT"],
        credential=AzureKeyCredential(os.environ["AZURE_VOICELIVE_API_KEY"]),
        model="gpt-4o-realtime-preview",
    ) as connection:
        # Oturumu yapılandır: hem metin hem ses modaliteleri, Türkçe nöral ses
        voice_config = AzureStandardVoice(name="tr-TR-EmelNeural", type="azure-standard")
        session = RequestSession(
            modalities=[Modality.TEXT, Modality.AUDIO],
            instructions="Sen sabırlı ve net konuşan Türkçe bir sesli asistansın.",
            voice=voice_config,
            input_audio_format=InputAudioFormat.PCM16,
            output_audio_format=OutputAudioFormat.PCM16,
            # Sunucu tabanlı ses etkinliği tespiti (VAD) — kullanıcı ne zaman
            # konuşmaya başlıyor/bitiriyor, otomatik algılanır
            turn_detection=ServerVad(threshold=0.5, prefix_padding_ms=300, silence_duration_ms=500),
        )
        await connection.session.update(session=session)

        # Gelen event'leri dinle
        async for event in connection:
            if event.type == ServerEventType.SESSION_UPDATED:
                print(f"Oturum hazır: {event.session.id}")
                # Burada mikrofon yakalamaya başlarsın (pyaudio ile)

            elif event.type == ServerEventType.INPUT_AUDIO_BUFFER_SPEECH_STARTED:
                print("Kullanıcı konuşmaya başladı — mevcut agent sesini KES")
                # audio_player.stop()  # kesinti (interrupt) burada işlenir

            elif event.type == ServerEventType.RESPONSE_AUDIO_DELTA:
                audio_bytes = event.delta
                # audio_player.play(audio_bytes)  # gelen ses parçasını çal

            elif event.type == ServerEventType.ERROR:
                print(f"Hata: {event.error.message}")

if __name__ == "__main__":
    asyncio.run(main())

Modül 07 / 07

Translate text and speech with Microsoft Foundry ToolsKursun kapanışı — metin hattı ile ses hattını "çeviri" ortak paydasında birleştiriyor.

Bu modül aslında ne anlatıyor?

Bu son modül, Modül 1'in metin becerileriyle Modül 4'ün ses becerilerini birleştirip, ikisini de diller arası çeviriye uyguluyor: Translator servisiyle metin çevirisi/harf çevirisi (transliteration), Speech SDK'nın çeviriye özel uzantısıyla da konuşma çevirisi.

Translate vs Transliterate — kritik ayrım

translate()Bir dildeki metni başka bir dile çevirir (anlam değişir/korunur, kelimeler değişir) — örn. Çince "你好" → İngilizce "Hello"
transliterate()Aynı dildeki metni bir alfabeden başka bir alfabeye aktarır (anlam/kelime AYNI kalır, sadece yazı sistemi değişir) — örn. Rusça Kiril "спасибо" → Latin harfleriyle "spasibo"
Quiz'de doğrudan sorulan iki fonksiyon çağrısı

Çince "你好"yu İngilizce "Hello"ya çevirmek için → translate (dil değişiyor).
Rusça Kiril "спасибо"yu Latin harfleriyle "spasibo" yapmak için → transliterate (dil aynı kalıyor Rusça, sadece alfabe değişiyor).

💻 Çalışır kod: Metin çevirisi ve harf çevirisi

metin_cevirisi.py
import os
from dotenv import load_dotenv
from azure.core.credentials import AzureKeyCredential
from azure.ai.translation.text import TextTranslationClient

load_dotenv()
client = TextTranslationClient(
    credential=AzureKeyCredential(os.environ["TRANSLATOR_KEY"]),
    region=os.environ["TRANSLATOR_REGION"],
)

# --- translate: DİL değişir ---
sonuc = client.translate(body=["你好"], to_language=["en"])
print("Çeviri:", sonuc[0].translations[0].text)   # -> "Hello"

# --- transliterate: sadece ALFABE değişir, dil aynı kalır ---
harf_sonucu = client.transliterate(
    body=["спасибо"],
    language="ru",
    from_script="Cyrl",   # Kiril
    to_script="Latn",     # Latin
)
print("Harf çevirisi:", harf_sonucu[0].text)   # -> "spasibo"

from dotenv import load_dotenv
import azure.cognitiveservices.speech as speechsdk

load_dotenv()

# SpeechTranslationConfig: hangi dilden hangi dillere çevrileceğini belirtir
translation_config = speechsdk.translation.SpeechTranslationConfig(
    subscription=os.environ["SPEECH_KEY"],
    region=os.environ["SPEECH_REGION"],
)
translation_config.speech_recognition_language = "tr-TR"   # kaynak dil
translation_config.add_target_language("en")                # hedef dil 1
translation_config.add_target_language("de")                # hedef dil 2 (birden fazla eklenebilir)

audio_config = speechsdk.audio.AudioConfig(filename="turkce_konusma.wav")
recognizer = speechsdk.translation.TranslationRecognizer(
    translation_config=translation_config,
    audio_config=audio_config,
)

result = recognizer.recognize_once()

if result.reason == speechsdk.ResultReason.TranslatedSpeech:
    print(f"Algılanan (tr): {result.text}")
    print(f"İngilizce çeviri: {result.translations['en']}")
    print(f"Almanca çeviri: {result.translations['de']}")
elif result.reason == speechsdk.ResultReason.NoMatch:
    print("Konuşma tanınamadı.")

İki çeviri modu — Azure Speech in Foundry Tools'un sunduğu

Speech-to-Text Translation: bir dildeki konuşmayı, başka bir dilde YAZILI metne çevirir.
Speech-to-Speech Translation: bir dildeki konuşmayı alır, başka bir dilde SÖZLÜ çıktı üretir (yukarıdaki kod + Modül 4'ün SpeechSynthesizer'ının birleşimi).

Sık karıştırılan noktalar (quiz odaklı)

Çince "你好"yu İngilizce "Hello"ya çevirmek için hangi fonksiyonu kullanırsın?
translate. get_supported_language (dil listesi döner, çeviri yapmaz) veya transliterate (sadece alfabe değiştirir, dil değiştirmez) değil.
Rusça Kiril "спасибо"yu Latin harfleriyle "spasibo" yapmak için hangi fonksiyonu kullanırsın?
transliterate. translate burada yanlış olur çünkü dil (Rusça) değişmiyor, sadece yazı sistemi (Kiril → Latin) değişiyor.
Konuşmanın hangi dil(ler)e çevrileceğini belirtmek için hangi Speech SDK nesnesini kullanırsın?
SpeechTranslationConfig. SpeechConfig (genel amaçlı, çeviriye özel değil) veya AudioConfig (sadece ses girdi/çıktısını tanımlar) değil.
