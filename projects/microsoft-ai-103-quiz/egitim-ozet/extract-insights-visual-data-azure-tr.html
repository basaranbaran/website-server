Extract insights from visual data on AzureGörsel anlama, görsel/video üretme ve Content Understanding / Document Intelligence / AI Search ile bilgi çıkarma — 8 modülün tamamı, sıfırdan, Türkçe.

Bu, sertifika yolundaki dördüncü kurs. Modül 01 / 08

Develop a vision-enabled generative AI applicationMultimodal bir modele hem metin hem resim gönderip yorum aldırma.

Bu modül aslında ne anlatıyor?

İlk kursta öğrendiğin chat uygulamalarına bir boyut daha eklenir: görsel girdi. Bazı modeller ("multimodal" modeller) sadece metni değil, resimleri de "okuyabilir" — bir fotoğrafa bakıp "bu meyve nedir, hangi tariflerde kullanılır" gibi sorulara cevap verebilirler.

Foundry'de hangi modeller görsel girdiyi destekler?

Phi-4-multimodal-instructMicrosoft — metin + resim girdisi
GPT-4.1 / GPT-4.1-miniOpenAI — metin + resim girdisi, geniş görsel anlama
Sık karışan nokta

Görsel girdiyi sadece OpenAI GPT modelleri değil, "multimodal" olarak etiketlenmiş herhangi bir model destekleyebilir (ör. Microsoft'un Phi-4-multimodal'ı). "Hangi model türü görsel girdiye cevap verebilir?" sorusunun doğru cevabı multimodal modellerdir — belirli bir sağlayıcı değil.

Multi-part prompt yapısı

Görsel içeren bir prompt, üç parçadan oluşur:

1) System / Developer Message Modelin rolünü ve davranışını tanımlar 2) Text Instruction "Bu görselde ne var?" gibi metin 3) Image Data URL referansı VEYA base64-encoded

Görseli iki şekilde gönderebilirsin: bir URL olarak (görsel herkese açık bir adreste barınıyorsa) veya base64 kodlanmış ikili veri olarak (yerel bir dosyayı gönderiyorsan).

💻 Çalışır kod: Vision chat uygulaması

Aşağıdaki kod, kursun resmi alıştırmasındaki image-chat-app.py dosyasının temelini oluşturur. Önce URL tabanlı bir görselle:

image_chat_url.py
import os
from dotenv import load_dotenv
from openai import OpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

load_dotenv()

# Keyless (Entra ID) kimlik doğrulama — kursun resmi alıştırmasının tercih ettiği yöntem
credential = DefaultAzureCredential()
token_provider = get_bearer_token_provider(credential, "https://ai.azure.com/.default")
client = OpenAI(
    base_url=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=token_provider(),
)

system_message = "Sen bir manav dükkanında müşterilere yardımcı olan, meyve/sebze konusunda uzman bir asistansın."
prompt = "Bu meyveyle hangi tatlıları yapabilirim?"
image_url = "https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/orange.jpeg"

response = client.responses.create(
    model=os.environ["MODEL_DEPLOYMENT"],
    input=[
        {"role": "developer", "content": system_message},
        {"role": "user", "content": [
            {"type": "input_text", "text": prompt},
            {"type": "input_image", "image_url": image_url}
        ]}
    ]
)
print(response.output_text)

Yerel bir dosyayı base64 ile göndermek istersen (URL yerine):

image_chat_base64.py
import base64
from pathlib import Path

# Get a response to image input
image_path = Path("mystery-fruit.jpeg")
image_format = "jpeg"
with open(image_path, "rb") as image_file:
    image_data = base64.b64encode(image_file.read()).decode("utf-8")

data_url = f"data:image/{image_format};base64,{image_data}"

response = client.responses.create(
    model=os.environ["MODEL_DEPLOYMENT"],
    input=[
        {"role": "developer", "content": system_message},
        {"role": "user", "content": [
            {"type": "input_text", "text": "Bu meyve nedir? Hangi tariflerde kullanabilirim?"},
            {"type": "input_image", "image_url": data_url}
        ]}
    ]
)
print(response.output_text)

Bu basit uygulamanın bir sınırı

Bu örnekte konuşma geçmişi tutulmuyor — her prompt, öncekinden habersiz yeni bir istek olarak işleniyor. Çok adımlı bir görsel sohbet istiyorsan, birinci kursun Modül 3'ündeki previous_response_id mantığını buraya da uygulayabilirsin.

Sık karıştırılan noktalar (quiz odaklı)

Görsel girdiye cevap üretmek için hangi model türünü kullanmalısın?
Multimodal modeller. Sadece OpenAI GPT modelleri değil — Phi-4-multimodal-instruct gibi Microsoft modelleri de görsel girdiyi destekler. Embedding modelleri görsel/metin üretmez, sadece vektör temsili çıkarır.
Bir modele resmi analiz etmesini isteyen bir prompt'u nasıl gönderirsin?
Hem metin hem görsel içerik barındıran tek, çok-parçalı (multi-part) bir kullanıcı mesajı göndererek. İki ayrı prompt (biri resim, biri metin) göndermek ya da resmi system message'a koymak doğru yaklaşım değildir.
Bir mesaja görsel nasıl dahil edilir?
Ya bir URL olarak, ya da base64 kodlanmış ikili veri olarak. Sadece biri değil, ikisi de desteklenir — hangisini kullanacağın görselin nerede barındığına bağlıdır.

Modül 02 / 08

Generate images with AIgpt-image ve FLUX modelleriyle sıfırdan, metinden görsel üretme.

Bu modül aslında ne anlatıyor?

Modül 1'de modele resim gösterip yorum aldırdın. Bu modülde bunun tam tersini yapıyorsun: modele metinle bir tarif verip yeni, daha önce hiç var olmamış bir görsel ürettiriyorsun.

Bu bir arama motoru değil

gpt-image-1 gibi modeller, hazır bir stok fotoğraf kütüphanesinden arama yapmaz — piksel piksel, eğitim sırasında öğrendiği örüntülerden yeni bir görsel inşa eder. Aynı prompt'u tekrar gönderdiğinde bile her seferinde benzersiz, farklı bir görsel üretir.

Foundry'deki modeller

gpt-image-1 / gpt-image-2Zengin detay, güçlü prompt takibi, görsel içine metin (yazı) render edebilme
FLUX serisiHızlı üretim, yüksek görsel kalite, birden fazla model varyantı ve stil esnekliği

Model kataloğunda nasıl bulursun?

Foundry model kataloğunda görsel üretim modeli ararken inference task (çıkarım görevi) filtresini "Text to image" olarak ayarlarsın — "Image to text" (bu görsel anlama, Modül 1) veya "Embeddings" değil. Bu modelleri OpenAI'ın Image API'siyle kullanırsın.

💻 Çalışır kod: Görsel üretme uygulaması

Kursun resmi alıştırmasındaki image-client.py temel alınarak:

image_client.py
import os, json, base64
from dotenv import load_dotenv
from openai import OpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

load_dotenv()

# Keyless kimlik doğrulama
token_provider = get_bearer_token_provider(
    DefaultAzureCredential(
        exclude_environment_credential=True,
        exclude_managed_identity_credential=True,
    ),
    "https://cognitiveservices.azure.com/.default",
)
client = OpenAI(
    base_url=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=token_provider(),
)

prompt = "Spagetti yiyen sevimli bir robot, stüdyo aydınlatmasıyla"

# gpt-image modeli görsel çıktıyı base64 olarak döner (URL olarak değil!)
img = client.images.generate(
    model=os.environ["IMAGE_MODEL_DEPLOYMENT"],
    prompt=prompt,
    n=1,
)

json_response = json.loads(img.model_dump_json())
image_data = json_response["data"][0].get("b64_json")
image_bytes = base64.b64decode(image_data)

os.makedirs("images", exist_ok=True)
with open("images/image_1.png", "wb") as f:
    f.write(image_bytes)

print("Görsel kaydedildi: images/image_1.png")

En sık yapılan hata

gpt-image modelleri her zaman base64-kodlanmış görsel verisi döner, URL değil (eski DALL-E modellerinin aksine). Kodun bir URL bekleyip response.data[0].url okumaya çalışırsan hata alırsın — b64_json alanını kullanman ve kendin decode edip dosyaya yazman gerekir.

Modül 03 / 08

Generate videos with Microsoft FoundrySora 2 ile metinden, resimden video üretme ve mevcut videoları remixleme.

Bu modül aslında ne anlatıyor?

Görsel üretiminden bir adım öteye: Sora 2 ile hareketli, gerçekçi video sahneleri üretiyorsun. Süreç asenkron çalışır — bir video işi (job) oluşturursun, durumunu kontrol edersin (poll), ve tamamlandığında indirirsin.

Sora 2'nin 3 yeteneği

Text to VideoSadece metin açıklamasından gerçekçi video sahneleri üretme
Image to VideoDurağan bir resmi hareketli, dinamik bir sahneye dönüştürme
Video RemixVar olan bir videoyu farklı renk paleti/görsel stille yeniden düzenleme

Ana akış: gönder → sorgula → indir

1) Submit Job 2) Poll for Status 3) Download videos.create() → "processing" mi → content = videos model, prompt, "completed" mi .download_content() resolution, "failed" mi duration (~20 saniyede bir kontrol et)

Anahtar özellikler

ÖzellikDeğer

Süre5 – 20 saniye arası klipler
En-boy oranı16:9, 9:16, 1:1
FormatMP4 çıktı
Referans görsel kullanırken dikkat

Sora 2'ye bir referans görsel verdiğinde, görselin çözünürlüğü hedef video boyutuyla eşleşmelidir — rastgele boyutta bir görsel kullanamazsın.

💻 Çalışır kod: Video üretme, sorgulama, indirme, remix

Kursun resmi alıştırmasındaki video-app.py temel alınarak, uçtan uca tam akış:

video_app.py
import time
from dotenv import load_dotenv
from openai import OpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider
import os

load_dotenv()
token_provider = get_bearer_token_provider(
    DefaultAzureCredential(), "https://cognitiveservices.azure.com/.default"
)
client = OpenAI(base_url=os.environ["AZURE_OPENAI_ENDPOINT"], api_key=token_provider())
model_deployment = os.environ["VIDEO_MODEL_DEPLOYMENT"]

def poll_video_status(video_id):
    video = client.videos.retrieve(video_id)
    while video.status not in ["completed", "failed", "cancelled"]:
        print(f"Durum: {video.status}. 20 saniye bekleniyor...")
        time.sleep(20)
        video = client.videos.retrieve(video_id)
    print("Video tamamlandı!" if video.status == "completed" else f"Video durumu: {video.status}")
    return video

def download_video(video_id, output_filename):
    print(f"{video_id} indiriliyor...")
    content = client.videos.download_content(video_id, variant="video")
    content.write_to_file(output_filename)
    print(f"Kaydedildi: {output_filename}")

def generate_video_from_image(image_path, prompt, size, seconds):
    video = client.videos.create(
        model=model_deployment,
        prompt=prompt,
        size=size,
        seconds=seconds,
        input_reference=open(image_path, "rb"),
    )
    return video

def remix_video(video_id, prompt):
    video = client.videos.remix(video_id=video_id, prompt=prompt)
    print(f"Remix başladı. Yeni video ID: {video.id}")
    return poll_video_status(video.id)

# --- 1) Metinden video üret ---
video = client.videos.create(
    model=model_deployment,
    prompt="Gün doğumunda sisli, huzurlu bir dağ gölü",
    size="1280x720",
    seconds="4",
)
video = poll_video_status(video.id)
if video.status == "completed":
    download_video(video.id, "original_video.mp4")

# --- 2) Resimden video üret ---
image_video = generate_video_from_image(
    image_path="reference.png",
    prompt="Sahne yumuşak bir hareket ve ortam ışığıyla canlanıyor",
    size="1280x720",
    seconds="4",
)
if image_video.status == "completed":
    download_video(image_video.id, "image_based_video.mp4")

# --- 3) Videoyu remixle ---
remixed = remix_video(video.id, "Sıcak, davetkar bir enstrümantal müzik ekle")
if remixed.status == "completed":
    download_video(remixed.id, "remixed_video.mp4")

Sık karıştırılan noktalar (quiz odaklı)

Sora 2 hangi video sürelerini destekler?
5 ile 20 saniye arası klipler (kurs materyalinde belirtilen aralıklarla — ör. 4, 8, 12 saniye gibi belirli artışlar). 1-60 saniye arası herhangi bir süre desteklenmez, sabit bir aralık vardır.

Analyze images with Content UnderstandingBir resmi, kendi tanımladığın şemaya göre yapılandırılmış veriye dönüştürme.

Azure Content Understanding, generative AI kullanarak görselleri (ve genel olarak her tür içeriği) analiz edip, senin tanımladığın bir şemaya göre yapılandırılmış veri döndüren bir Foundry Tools yeteneğidir. Bu modül, işin sadece "resim" tarafına odaklanıyor.

Custom (özel)Kendi işine özgü ihtiyaçlar için kendi şemanı, kendi kurallarınla tanımlarsın

Grounding (temellendirme) nedir?

Grounding'in amacı, çıkarılan her değerin içerikte tam olarak nereden geldiğini belirlemektir — yani model "bu bilgiyi resmin şu bölgesinden aldım" diyebilir. Bu, Azure storage'a bağlanmakla veya zararlı içerik filtrelemekle ilgili değildir; izlenebilirlik ve doğrulanabilirlik sağlamaktır.

Confidence score (güven skoru) nasıl okunur?

0 ile 1 arasında bir değer alır. 0.95 gibi yüksek bir skor, o değerin otomatik işlemede güvenle kullanılabileceği anlamına gelir — düşük skorlar (ör. 0.4) manuel gözden geçirme gerektirebilir. Yüksek skor "extraction başarısız oldu" ya da "bu alan sınıflandırıldı, çıkarılmadı" anlamına gelmez.

Portal odaklı bir modül: Content Understanding Studio

Bu modülde kod yazmadan önce Content Understanding Studio üzerinde bir analyzer oluşturursun:

  1. Foundry kaynağını Content Understanding Studio'ya bağla (Settings → Add resource).
  2. Yeni bir proje oluştur: "Extract content and field with custom schema" tipini seç.
  3. Bir örnek resim yükle, şablon olarak Image Analysis seç.
  4. Schema'ya alan ekle: ör. Description (String, Generate), Tags (List of Strings, Generate).
  5. Run analysis ile test et, sonuçlardan memnun kalınca Build analyzer ile yayınla — bir isim ver, bu ismi kodda kullanacaksın.

Indexer nedir?

Herhangi bir şeyi aratabilmen için önce indekslemen gerekir. Azure AI Search'te bu iş indexer'a aittir:

Connects to Extracts & Builds a data sources → enriches content → searchable index

Skillset — AI ile zenginleştirme

Bir indexer, ham veriyi çekmenin ötesine geçip AI skills ile veriyi zenginleştirebilir (OCR, entity recognition, key phrase extraction, çeviri, duygu analizi).   • Özel eşleme — bir alanı yeniden adlandırmak veya değerini dönüştürmek istediğinde kendin tanımlarsın (ör. img_text → imageText).

)
indexer_client.create_or_update_data_source_connection(data_source)

# 3) Skillset ile AI zenginleştirmesi ekle (Enrich) — Foundry Tools destekli built-in skill
skillset = SearchIndexerSkillset(
    name="zenginlestirme-skillset",
    skills=[
        EntityRecognitionSkill(
            inputs=[InputFieldMappingEntry(name="text", source="/document/content")],
            outputs=[OutputFieldMappingEntry(name="organizations", target_name="organizations")],
        )
    ],
    # Knowledge store: zenginleştirilmiş veriyi indeksin ötesinde de sakla
    knowledge_store=SearchIndexerKnowledgeStore(
        storage_connection_string=os.environ["STORAGE_CONNECTION_STRING"],
        projections=[
            SearchIndexerKnowledgeStoreProjection(
                tables=[
                    SearchIndexerKnowledgeStoreTableProjectionSelector(
                        table_name="Organizasyonlar",
                        generated_key_name="orgId",
                        source="/document/organizations/*",
                    )
                ]
            )
        ],
    ),
)
indexer_client.create_or_update_skillset(skillset)

# 4) Indexer'ı oluştur ve çalıştır (Explore için hazır hale getirir)
indexer = SearchIndexer(
    name="belge-indexer",
    data_source_name="belge-kaynagi",
    target_index_name="belge-index",
    skillset_name="zenginlestirme-skillset",
    field_mappings=[
        FieldMapping(source_field_name="metadata_storage_path", target_field_name="metadata_storage_path"),
    ],
)
indexer_client.create_or_update_indexer(indexer)
print("Indexer oluşturuldu ve çalışmaya başladı.")

Çalıştırmak için: pip install azure-search-documents sonra python bilgi_madenciligi.py

Bu kodu Modül 1-7 ile birleştirirsen

Gerçek bir "bilgi madenciliği" çözümünde, Content Understanding (Modül 4-6) veya Document Intelligence (Modül 7) ile çıkardığın yapılandırılmış veriyi skillset'e özel bir "skill" olarak ekleyebilir, sonucu bu indexer pipeline'ına dahil edebilirsin — bu kurs, aslında sana bu 8 parçayı birbirine bağlayabileceğin bir araç kutusu veriyor.

Sık karıştırılan noktalar (quiz odaklı)

Bir Azure AI Search çözümünde, bir indeksi doldurmak için veriyi çıkarıp zenginleştirmek üzere hangi bileşen zamanlanır (scheduled)?
Indexer. Projection (izdüşüm) knowledge store'un bir parçasıdır, veri çekmez; query ise arama yapmak içindir, indeksleme değil.
Azure AI Search'te yerleşik AI skill'lerini hangi servis destekler?
Foundry Tools. Azure Functions (kendi custom skill'lerini barındırmak için kullanılabilir ama yerleşik skill sağlayıcısı değildir) veya Azure Cosmos DB değil.
Hangi projection tipi, çıkarılan alanlar için ilişkisel (relational) bir veri şeması oluşturur?
Table. File görsel/dosya çıktısı, Object ise JSON belge koleksiyonu üretir — ikisi de satır/sütun ilişkisel yapı değildir.
