Temel Güvenlik Farkları

Çalışma Kullanıcısı

Standard root — Tam yetki, tehlikeli!
Hardened nonroot — Kısıtlı, güvenli

Shell Erişimi

Standard /bin/sh mevcut — Saldırgan komut çalıştırabilir
Hardened Shell yok — Saldırgan eli boş döner

İmaj Boyutu & Paketler

Gerçek Test Çıktısı

Kendi Bilgisayarınızda Deneyin

Aşağıdaki komutları Docker kurulu herhangi bir bilgisayarda çalıştırarak farkları görebilirsiniz.

1 Docker Hub ve DHI'a Giriş 
docker login
docker login dhi.io
2 İmajları Oluştur (Build) 
# Standard imaj
docker build -f Dockerfile.standard -t demo-standard .

# Hardened imaj
docker build -f Dockerfile.hardened -t demo-hardened .
3 Test A: Kullanıcı Kontrolü 
docker run --rm demo-standard whoami
# Çıktı: root (Güvensiz!)

docker run --rm demo-hardened whoami
# Çıktı: nonroot (Güvenli!)
4 Test B: Shell Erişimi (Saldırı Senaryosu) 
docker run --rm -it demo-standard /bin/sh
# Shell açılır - tehlikeli!

docker run --rm -it demo-hardened /bin/sh
# "no such file or directory" - güvenli!
5 Test C: Dosya Yazma (Exploit Senaryosu) 
docker run --rm demo-standard sh -c "touch /etc/hACKED && echo 'Sızdım!'"
# Başarılı - root yetkisi var!

docker run --rm demo-hardened sh -c "touch /etc/hACKED"
# Başarısız - shell bile yok!
