Kendi Bilgisayarında Çalıştır

Kaynak kod tamamen açık. Klonlayıp bağımlılık kurmadan (sadece Python standart kütüphanesi kullanılıyor) doğrudan çalıştırabilirsin.

1 Repoyu Klonla 
git clone {{ info.github }}/microsoft-ai-103-quiz.git
cd microsoft-ai-103-quiz
2 Sunucuyu Başlat 
# Ekstra bağımlılık yok, sadece Python 3 yeterli
python3 server.py
# -> http://localhost:6321
3 Tarayıcıda Aç 
http://localhost:6321

Docker İmajı Olarak Çalıştır

Repo, hazır bir Dockerfile ve docker-compose.yml ile geliyor. Docker kurulu herhangi bir makinede saniyeler içinde ayağa kaldırabilirsin.

1 Repoyu Klonla ve İmajı Build Et 
git clone {{ info.github }}/microsoft-ai-103-quiz.git
cd microsoft-ai-103-quiz
docker build -t microsoft-ai-103-quiz .
2 Container'ı Çalıştır 
docker run -d -p 6321:6321 --name ai103-quiz microsoft-ai-103-quiz
# -> http://localhost:6321
3 Ya da docker-compose ile 
docker compose up -d
# -> http://localhost:6321
4 Sağlık Kontrolü 
curl http://localhost:6321/api/health
# {"status": "healthy", ...}
